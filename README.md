# AU-Personal-Website

This is my personal website specifically built to be hosted on my university's server at <https://www.andrews.edu/~monroel>
This project utilizes GitHub actions to automatically push my front-end files to the server using rsync.

## Development
Yes, this project uses AI. Quite heavily. It's a great experiment and allows me to make complex front-end features without spending an unreasonable amount of time on them.

## Local Testing

The npm package files and vite config file are solely for local deployment and testing.
Run `npm install` and `npm run dev` to run the website locally.
